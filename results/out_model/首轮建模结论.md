# LIDC-IDRI 首个 AUC · 结果与诊断

生成时间：2026-11-15
脚本：`build_model.py`（嵌套 CV，LASSO-L1 逻辑回归，按 patient_id 分组）
数据：`features/nodules_features.csv`（602 结节 / 302 例，100% 匹配）

---

## 1. 主结果

| 项目 | 数值 |
|---|---|
| 样本 | 322 结节 / 206 病人（恶 130 : 良 192 = 0.68 : 1） |
| 剔除 | 灰区（malignancy=3）280 结节 |
| **AUC** | **0.975 ± 0.003**（5 折 × 5 次重复） |
| 95% CI | 0.960 – 0.987（病人级聚类 bootstrap，2000 次） |
| Brier | 0.059（无信息基线 0.25） |
| 置换检验 | p = 0.010（100 次，零分布 0.491 ± 0.042） |
| 每折入选特征 | 12.0 ± 5.5 个 |

病例级敏感性分析（同一病例取结节预测最大值）：206 例，AUC 0.982。

## 2. 参照模型——问题在这里

## 3. 增量检验

| 分析 | ΔAUC（纹理−直径） | 95% CI | 判定 |
|---|---|---|---|
| 全样本，直径强制入模 | −0.002 | −0.009 ~ +0.005 | 无增量 |
| 10–15mm 区间（n=55，29 恶 / 26 良） | −0.035 | −0.160 ~ +0.093 | 无增量 |

10–15mm 区间内：直径单变量 AUC 0.800，加纹理后 0.769。纹理不但没帮忙，还带来了过拟合噪声（每折入选 10.7 ± 6.0 个特征，样本只有 55）。

## 4. 原因：标签本质是尺寸的单调函数

| 直径段 | n | 恶性率 | 灰区率 |
|---|---|---|---|
| ≤6mm | 50 | 0% | 52% |
| 6–8mm | 171 | 0% | 49% |
| 8–10mm | 129 | 3.1% | 59% |
| 10–12mm | 61 | 9.8% | 57% |
| 12–15mm | 60 | 38.3% | 52% |
| 15–20mm | 50 | 58.0% | 34% |
| >20mm | 81 | 84.0% | 15% |

- 直径中位：恶性 20.5mm，良性 7.6mm
- Spearman ρ(直径, malignancy 1–5) = 0.768
- diameter 单变量 AUC = 0.980

LIDC 的 `malignancy` 是放射科医师的主观 1–5 分，不是病理诊断。这个分数与结节大小几乎共线。因此在此标签上做"良恶性预测"，等价于做"体积估计"，而影像组学估体积当然准。

## 5. 关键旁证：灰区与大小无关

用直径区分"灰区(3分) vs 医师确信(1-2/4-5)"：AUC 0.401（等效 0.599），几乎无判别力。灰区比例在 ≤15mm 各段稳定在 50% 上下，>15mm 才下降。

**结论：医师分歧是一个与大小近似正交的终点，纹理特征在这个终点上才有发挥空间。**

## 6. 判定

- 首个 AUC 已产出，统计上显著（p=0.010），但**没有增量价值**，不具备"影像组学优于尺寸"的结论基础。
- 直接写"LIDC 良恶性分类 AUC 0.975"可以发表，但属于把尺寸当影像组学的常见做法；一旦审稿人要求 size-adjusted 分析就会塌。
- 真正的科学问题只剩两个方向：
  1. **负结果**：报告"在 LIDC malignancy 评分上，影像组学相对于直径无增量"，附完整增量检验与 CI。方法学上站得住，也少见。
  2. **换终点**：以"医师分歧/灰区"为目标（280 灰区 vs 322 确信，比例接近 1:1，且与大小正交），检验纹理能否解释放射科医师的不确定性。
